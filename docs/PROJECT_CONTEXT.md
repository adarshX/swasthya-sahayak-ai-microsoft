# Project Context

Project
Swasthya Sahayak AI

Purpose

Provide real-time decision-support to frontline health workers in rural India.

Users

ASHA workers
ANMs
Primary Health Center staff

Problem

Frontline workers must manually remember clinical guidelines.

This leads to:

inconsistent triage
delayed escalation
avoidable hospital visits

Solution

An offline-first clinical assistant that guides workers through symptom capture and triage.

System Characteristics

Offline-first
Voice-enabled
Protocol-driven
Cloud-sync capable

Clinical decisions are produced using predefined health guidelines.

AI is used only to enhance usability.

Triage Outcomes

Home Care
PHC Visit
Urgent Referral
